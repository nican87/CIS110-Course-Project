Birthday Trip Planning Program

Overview

This Python coursework project creates an interactive birthday-trip scenario based on user preferences.

Features

* Collects information about the user’s birthday and preferences.
* Asks questions about age, weather, and clothing preferences.
* Uses conditional statements to generate different travel-related responses.
* Provides an interactive, text-based experience.

Technologies

* Python

Background

Created as part of CIS110 programming coursework at Strayer University.
